# SOL H04 OOS Failure Anatomy A1 — Preregistration

## Purpose

Explain why the frozen SOLUSDT LONG H04 winner (`EFF_LOW__RANGE_HIGH / LB360 / hold240m`, 11:00–12:00 WIB) remained profitable in Development and early OOS but degraded in 2025–2026, without changing the frozen entry rule, lookback, hold, anchors, fee, or market mechanics.

This experiment is diagnostic only. It is not allowed to create or promote a rescue filter.

## Frozen cohort

Use only trades generated by the exact H04 winner:
- SOLUSDT Binance USD-M Futures 5m.
- LONG only.
- UTC anchors 04:00 / 04:15 / 04:30 / 04:45.
- Rule `EFF_LOW__RANGE_HIGH`.
- Lookback 360 minutes.
- Hold 240 minutes.
- Exact-open entry and exact-open time exit.
- $500 notional and $0.75 round-trip fee.
- Same causal percentile normalization as discovery.

No alternative rule, lookback, hold, anchor subset, TP, SL, or threshold may be searched.

## Partitions

Use repository partitions exactly:
- external: 2020-01-01 to 2021-12-31.
- development: 2022-01-01 to 2024-12-31.
- reference_validation: 2025-01-01 to 2026-07-29.

The previously exposed OOS result is accepted as the reason for this anatomy experiment. August 2026 remains excluded.

## Questions

A1 tests two diagnostic questions only:

1. **Pre-entry regime shift:** did the causal market state surrounding frozen H04 trades change materially between Development / External and Reference Validation, especially 2026?
2. **Post-entry path degradation:** did the same frozen entries stop receiving favorable excursion, or did they still move favorably but give back gains before the frozen 240m exit?

## Frozen pre-entry diagnostic features

All are measured strictly before or at entry and do not alter trade selection:

### Frozen-rule intensity
- raw 360m directional efficiency.
- raw 360m realized range.
- 360m drive return.
- existing causal efficiency percentile.
- existing causal range percentile.

### Broader causal regime
- trailing 24h return.
- trailing 72h return.
- trailing 7d return.
- trailing 24h realized range.
- trailing 72h realized range.
- entry location inside trailing 24h high-low range.
- entry location inside trailing 7d high-low range.

### Calendar diagnostics
- quarter-hour anchor.
- weekday.
- calendar year and month.

No additional feature family may be added after inspecting A1 output.

## Frozen post-entry diagnostics

Over the exact 240m frozen holding window, report only:
- final gross/net return.
- MFE percentage from entry open.
- MAE percentage from entry open.
- giveback = MFE percentage minus final gross return percentage.
- whether a trade had MFE >= +1.0% but finished net negative.
- whether a trade had MFE >= +2.0% but finished net negative.

These are diagnostics only; no TP or stop rule is tested here.

## Development-anchored binning

For each continuous pre-entry diagnostic feature:
- calculate tercile boundaries from the **Development H04 cohort only**;
- freeze those boundaries;
- map External and Reference Validation observations into those Development-defined bins;
- report N, WR, net PnL, expectancy, PF, DD, and loss streak by partition and bin.

Do not calculate OOS-specific cut points.

## Distribution-shift diagnostics

For each pre-entry feature report:
- Development median and IQR.
- External median and IQR.
- Reference Validation median and IQR.
- 2025 median and IQR.
- 2026 median and IQR.
- population stability index (PSI) versus Development using the frozen Development tercile bins.

PSI is descriptive, not a trading threshold.

## Outcome/path diagnostics

Report frozen H04 economics by:
- partition;
- year;
- anchor;
- weekday;
- month;
- Development-defined feature tercile.

Report MFE/MAE/giveback medians and the two giveback-loss rates for the same partition/year splits.

## Interpretation rules

Classify the anatomy using only these labels:

- `PRE_ENTRY_REGIME_SHIFT_DOMINANT`: Reference Validation/2026 materially changes one or more preregistered pre-entry feature distributions and the weakest Development-defined bins concentrate the economic failure.
- `POST_ENTRY_PATH_DEGRADATION_DOMINANT`: pre-entry distributions remain broadly similar, but Reference Validation/2026 has materially worse MFE/MAE/giveback behavior.
- `MIXED_REGIME_AND_PATH_DEGRADATION`: both patterns are present.
- `NO_CLEAR_ANATOMY`: neither pattern is clear.

Because this is descriptive research, no single numerical PSI or MFE threshold is used to force a label. The report must show the full diagnostics supporting the classification.

## Stop rule

After A1 is run:

- do not retune H04;
- do not substitute the second Development passer;
- do not change the frozen exit.

If A1 finds a coherent mechanism, any secondary-confirmation or exit experiment must be separately preregistered on a new branch.
