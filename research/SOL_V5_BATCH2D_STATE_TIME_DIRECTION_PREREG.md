# SOL V5 Batch 2D — State-Time Direction Selector PREREG

## Objective
Test whether the LONG-capable subset of frozen V4 HIGH_STATE episodes can be identified **at the exact HIGH_STATE onset**, before any post-state candle is observed.

This is the direct answer to the latency problem found in Batch 2 / 2B / 2C:
- V4 detects an expansion habitat;
- post-state direction can be classified, but confirmation arrives too late;
- entering all HIGH_STATE episodes is negative;
- therefore the next question is whether pre-existing state geometry already contains enough directional information to select LONG episodes at t=0.

## Research boundary
- SOLUSDT Futures 5m, weekdays.
- Same frozen V4 state detector and Batch 1 HIGH_STATE episode definition.
- Research/development years: 2020–2024.
- Nested OOS test: 2022, 2023, 2024.
- `2025+ reference_validation` remains CLOSED.

## Universe
Only causal HIGH_STATE episode starts generated by the frozen V4 detector.

## Decision time
Exactly at HIGH_STATE `entry_time` / `anchor_price`.
No candle after state onset may enter the feature vector.

## Features
State-time-only features:
1. the frozen V4 causal feature vector (`v4.FEATURES`), all computed before/at state onset;
2. V4 `pred_impulse` score;
3. `state_margin = pred_impulse - state_cutoff`;
4. causal `sigma60_pct` and frozen `impulse_threshold_pct`.

No post-state return, MFE, MAE, barrier timing, activation feature, future volume, or future candle feature is allowed.

## Target
Binary directional target:
- `1` if the frozen Batch 1 future-path label is `UP_FIRST` within +120m;
- `0` otherwise.

This target is used for training only. It is never used as an input feature.

## Model
One deterministic `ExtraTreesClassifier`, matching Batch 2 architecture:
- n_estimators = 320
- max_depth = 8
- min_samples_leaf = 20
- max_features = "sqrt"
- class_weight = "balanced"
- random_state = 42
- n_jobs = -1

No model or hyperparameter sweep.

## Nested walk-forward
- predict 2022 from HIGH_STATE episodes in 2021;
- predict 2023 from 2021–2022;
- predict 2024 from 2022–2023.

All training episodes themselves must be causal V4 HIGH_STATE episodes from their original OOS year.

## Frozen selector
For each fold:
- fit the state-time direction classifier on the allowed past years;
- calculate classifier scores on that training set;
- freeze the selection cutoff at the **training-score 90th percentile**, matching Batch 2's frozen directional selectivity;
- select a LONG at t=0 when test score >= that causal cutoff.

No threshold sweep.

## Execution diagnostic
For selected episodes only:
- LONG entry at state `anchor_price` / state 5m open;
- fixed exit at +60m close;
- round-trip cost = 0.15%;
- $500 notional/trade;
- no TP, SL, trailing stop, time-stop, scaling, or exit optimization.

The +60m hold is only a diagnostic to test whether state-time selection creates actionable positive entry edge.

## Baseline
All HIGH_STATE episode starts in the same 2022–2024 test universe, entered at state onset and held +60m with identical cost.

## Metrics
- checkpoint-free state-time ROC AUC;
- selected N and selection rate;
- selected UP_FIRST rate and lift versus all HIGH_STATE;
- fixed +60m WR, net expectancy, PF, PnL, max DD, max loss streak;
- paired comparison to all HIGH_STATE baseline;
- year stability 2022/2023/2024;
- feature importance as diagnostic only.

## Frozen PASS gates
All must pass:
1. selected N >= 200;
2. OOS ROC AUC >= 0.55;
3. selected UP_FIRST rate >= 50%;
4. selected UP_FIRST lift >= 1.35x versus HIGH_STATE baseline;
5. selected fixed +60m net expectancy > 0;
6. selected fixed +60m PF >= 1.10;
7. positive selected PnL in >=2 of 3 test years.

## Stop rule
If Batch 2D fails, do not rescue it by sweeping score percentile, model family, fixed horizon, TP, SL, or hour filters on 2022–2024. The failure would mean that the currently encoded V4 state representation does not expose enough t=0 LONG direction for actionable early entry, even though direction becomes clearer after the move starts.
