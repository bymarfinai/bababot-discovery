# SOL V5 Batch 2E — Directional Sequence Representation PREREG

## Objective
Test whether the weak but non-zero t=0 directional information found in Batch 2D becomes actionable when the **24 completed 5m candles immediately preceding HIGH_STATE onset are encoded as an explicit directional path**, rather than relying mainly on snapshot / aggregate state descriptors.

This is a representation test, not a model search.

## Why this batch exists
Frozen findings before this prereg:
- V4 HIGH_STATE is a useful expansion-habitat detector.
- Batch 2 post-state direction is materially predictable, but confirmation arrives after edge is consumed.
- Batch 2D state-time direction has only weak OOS separation (AUC about 0.555) and negative +60m economics.
- Batch 2D feature importance showed positional candle features such as late-window volume, close-location and body/range variables, suggesting the **ordered path** may contain information that aggregate descriptors do not express cleanly.

## Research boundary
- SOLUSDT Futures 5m, weekdays.
- Same frozen V4 detector and Batch 1 HIGH_STATE episode definition.
- Research/development years: 2020–2024.
- Nested OOS tests: 2022, 2023, 2024.
- `2025+ reference_validation` remains CLOSED.

## Universe
Only causal HIGH_STATE episode starts generated by frozen V4.

## Decision time / anti-leakage
Decision is exactly HIGH_STATE `entry_time` / `anchor_price`.

For an episode at index `p`, sequence input is **only** the 24 fully completed 5m bars `p-24 ... p-1`.
The bar beginning at `entry_time` is not part of the sequence representation.
No post-state return, MFE, MAE, barrier timing, future volume, future candle, or Batch 2 checkpoint feature is allowed.

## Fixed 24-bar directional sequence representation
For each of the 24 pre-state bars, create causal, scale-normalized channels:
1. close displacement from the first sequence close, divided by state `sigma60_pct`;
2. one-bar close return divided by state `sigma60_pct`;
3. candle range divided by state `sigma60_pct`;
4. signed body fraction of candle range;
5. close location within candle range;
6. lower-wick fraction;
7. upper-wick fraction;
8. log volume relative to the 24-bar median volume;
9. higher-high indicator versus previous bar;
10. higher-low indicator versus previous bar;
11. lower-high indicator versus previous bar;
12. lower-low indicator versus previous bar;
13. close distance below running high, divided by state `sigma60_pct`;
14. close distance above running low, divided by state `sigma60_pct`.

The explicit per-bar sequence is augmented with **fixed relational summaries** computed from the same 24 completed bars only:
- HH+HL minus LH+LL balance over the final 4, 8, 12 and 24 bars;
- signed body balance over the final 4, 8, 12 and 24 bars;
- close-location shift: final-4 mean minus first-4 mean;
- volume shift: final-4 mean relative-volume minus first-4 mean relative-volume;
- range expansion: final-4 mean normalized range divided by first-4 mean normalized range;
- displacement acceleration: return over final 4 bars minus preceding 4 bars, normalized by sigma;
- downside sweep/reclaim in final 6 bars versus prior 18 bars;
- upside sweep/reject in final 6 bars versus prior 18 bars.

State context retained only to describe the habitat:
- `pred_impulse`;
- `state_margin`;
- `sigma60_pct`;
- `impulse_threshold_pct`.

No hour filter and no hand-coded bullish threshold is allowed.

## Target
Same target as Batch 2D:
- `1` = frozen Batch 1 path label is `UP_FIRST` within +120m;
- `0` = otherwise.

Target is training-only and is never an input.

## Model — frozen to isolate representation
Use the exact deterministic ExtraTrees architecture from Batch 2 / 2D:
- n_estimators = 320
- max_depth = 8
- min_samples_leaf = 20
- max_features = "sqrt"
- class_weight = "balanced"
- random_state = 42
- n_jobs = -1

No model or hyperparameter sweep.

## Nested walk-forward
Same as Batch 2D:
- predict 2022 from OOS HIGH_STATE episodes in 2021;
- predict 2023 from 2021–2022;
- predict 2024 from 2022–2023.

## Frozen selector
For each fold:
- fit on allowed prior OOS HIGH_STATE episodes;
- calculate scores on that fold's training episodes;
- freeze LONG cutoff at the **training-score 90th percentile**;
- select LONG at state onset when test score >= that cutoff.

No threshold sweep.

## Execution diagnostic
Selected episodes only:
- LONG entry at state `anchor_price` / state 5m open;
- exit fixed +60m close;
- 0.15% round-trip cost;
- $500 notional;
- no TP, SL, trailing stop, scaling, adaptive exit, or horizon optimization.

## Baselines
Report:
1. all HIGH_STATE episodes in the same 2022–2024 OOS universe;
2. Batch 2D frozen result values as historical comparison only (not used for tuning).

## Metrics
- OOS ROC AUC;
- selected N / rate;
- selected UP_FIRST / lift;
- selected +60m WR, expectancy, PF, PnL, DD, loss streak;
- yearly 2022/2023/2024 stability;
- feature/channel importance diagnostics;
- comparison with all HIGH_STATE baseline.

## Frozen PASS gates
Use the **same gates as Batch 2D**; all must pass:
1. selected N >= 200;
2. OOS ROC AUC >= 0.55;
3. selected UP_FIRST >= 50%;
4. selected UP_FIRST lift >= 1.35x versus all HIGH_STATE;
5. selected fixed +60m net expectancy > 0;
6. selected fixed +60m PF >= 1.10;
7. positive selected PnL in >=2 of 3 test years.

## Stop rule
If Batch 2E fails, do not rescue it by sweeping sequence length, channels, cutoff percentile, model family, hours, fixed exit horizon, TP, or SL on 2022–2024. The next decision must come from the failure mode itself, not another arbitrary parameter search.
