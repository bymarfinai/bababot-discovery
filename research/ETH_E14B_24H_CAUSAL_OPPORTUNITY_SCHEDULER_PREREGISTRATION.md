# ETH E14B — 24H Causal Opportunity-Cost Scheduler Preregistration

## Status
Development-only discovery. OOS CLOSED. No live authorization.

## Question
Can the frozen 24-hour ETH LONG character map be used as a temporal opportunity scheduler — TAKE now versus WAIT for future opportunities — while preserving native E12 entry rules, lookbacks, native fixed-hold payoff horizons, $500 notional, and one active position max?

E14B treats all 24 frozen E12 hourly representatives as eligible signal sources for discovery. This does **not** relabel E12 FAIL hours as formal PASS.

## Frozen data and execution semantics
- Pair: ETHUSDT 5m.
- Development: existing 2022/2023/2024 partition only.
- OOS remains closed.
- Signal source for each WIB hour: exact frozen E12 representative rule + lookback from the 24h map.
- Entry: original causal quarter-hour anchor opportunity generated by the E12/E13C machinery.
- Exit after TAKE: exact native fixed hold of that source hour (H240/H360/H720/H960 as frozen in E12 map).
- One active position max; all signals while busy are `SKIPPED_BUSY`.
- At exact exit timestamp the scheduler is flat again and may evaluate a signal at that timestamp.
- Notional: $500 per executed trade.
- Fee: existing $0.75/trade convention.
- No TP, SL, first-green close, averaging, pyramiding, DCA, or daily forced flat.

## Why E14B exists
E13C showed that first-valid sequential execution destroys many independent 24h opportunities through occupancy. E14A showed that forcing a common 23:00 WIB exit damages the native payoff structure. E14B therefore keeps native holds and uses the 24h map to price the opportunity cost of consuming the single capital slot now.

## Prior construction
Before replaying scheduler policies, build the full independent Development opportunity table using the frozen 24h map.

For each WIB source hour h:
1. `signal_probability_h` = total independent opportunities for h divided by the number of scheduled quarter-hour anchor slots for h in Development.
2. Compute independent fixed-native-hold expectancy for each year 2022, 2023, 2024.
3. `conservative_edge_h` = minimum of the three yearly expectancies.
4. Negative conservative edges are clipped to zero **for continuation-value estimation only**: `q_h = max(0, conservative_edge_h)`.

The realized PnL of any executed trade is always the true native-hold PnL from the opportunity ledger, never `q_h`.

Using all Development years to construct this frozen prior is explicitly Development-selected/in-sample research; it is not OOS evidence and will not be described as such.

## Bellman continuation-value engine
Discretize time into 15-minute slots. The frozen 24h map repeats every 96 slots.

For a slot belonging to hour h:
- `p_t = signal_probability_h`
- `q_t = q_h`
- `d_t = native_hold_min_h / 15`

Construct a repeated 60-day synthetic calendar of these slot-level priors and solve backward with terminal value zero:

`V[t] = (1-p_t)*V[t+1] + p_t*max(q_t + V[t+d_t], V[t+1])`

The TAKE-vs-WAIT advantage at a slot where a real signal is present is:

`ADV[t] = q_t + V[t+d_t] - V[t+1]`

To avoid end-boundary effects, scheduler decisions use the slot-of-day advantages extracted from the middle of the repeated horizon after at least 20 future repeated days remain. The 96 slot-of-day advantages are frozen before chronological replay.

This Bellman model assumes independent signal arrivals across future slots. That is a simplifying approximation and will be stated as such.

## Preregistered policy family
Reference policy:
- `FIRST_VALID_ALL24`: take every eligible signal when flat (E13C all-24 semantics).

Scheduler reservation-margin policies:
- `OC_M000`: TAKE if ADV >= $0.00
- `OC_M025`: TAKE if ADV >= $0.25
- `OC_M050`: TAKE if ADV >= $0.50
- `OC_M075`: TAKE if ADV >= $0.75
- `OC_M100`: TAKE if ADV >= $1.00
- `OC_M150`: TAKE if ADV >= $1.50
- `OC_M200`: TAKE if ADV >= $2.00
- `OC_M300`: TAKE if ADV >= $3.00

If flat and a signal does not satisfy the policy margin, log `SKIPPED_WAIT_VALUE` and preserve capital for later opportunities. No policy may inspect future realized signals or prices.

## Frozen robustness gate
A scheduler candidate is ROBUST only if:

Pooled:
- N >= 160
- WR >= 55%
- net > 0
- expectancy >= +$0.50/trade
- PF >= 1.20
- max DD <= $131.02 (E13C formal-pass sequential DD ceiling)
- max loss streak <= 8

Era, for every 2022/2023/2024:
- N >= 40
- WR >= 52%
- net > 0
- expectancy > 0
- PF >= 1.05
- at least 2 of 3 years WR >=55%

## Ranking among ROBUST schedulers
1. minimum yearly expectancy descending
2. number of years WR>=55% descending
3. expectancy descending
4. PF descending
5. WR descending
6. DD ascending
7. max loss streak ascending
8. Net PnL descending
9. N descending
10. lower reservation margin preferred as final tie-break
